# Provenance

Canonical values carry provider, dataset, original identifier where available, source URL, observation and retrieval/processing timestamps, agent/version, method, license and quality caveats. Derived values reference upstream identifiers. Forecast artifacts must match both the registered model ID and dataset fingerprint.

The canonical JSON is the complete provenance record; the RDF projection currently exposes a subset of its fields. Never infer exact coverage, live facility operation or calibrated uncertainty from source identity alone. Official climate features remain official_modelled even when retrieved today.
