# Relationship to The World Avatar

The project adopts the architectural idea of specialized agents interoperating through explicit semantic identities, provenance and typed data. It is an independent implementation with no affiliation or equivalence claim.

The current runtime is a small single-host Python application with persisted snapshots and RDF projection. It does not implement the distributed knowledge-graph infrastructure, agent deployment machinery or breadth of scientific models associated with a mature federated digital-twin ecosystem. Describe these as inspirations and future requirements, not completed capabilities.
